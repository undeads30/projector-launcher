# Сведения о проекторе

Этот файл — справка для следующих обращений. Сначала читайте его и README.md;
не запрашивайте у владельца повторно уже подтверждённые сведения.

## Подтверждено материалами репозитория

- Название устройства в README.md: **Cronus**. Точная торговая модель и
  производитель аппаратной платформы пока не установлены.
- Платформа проекта: Android / Android TV. Фактическая версия Android устройства
  пока не считана; упоминание Android 8–9 в README описывает поддержку Wi-Fi,
  а не подтверждает версию прошивки.
- Лаунчер: `com.gathin.tvhome`, основная Activity: `.MainActivity`.
- Помощник закрытия HDMI-уведомлений: `ru.projector.hdmiautoclose`.
- VPN-клиент, описанный в проекте: v2rayNG; профили HK / RU.
- Резервные APK: `dist/LauncherTV.apk` и `dist/HDMI-Autoclose.apk`.
- Инструкция подключения использует ADB по сети, порт `5555`.
  Актуальный IP-адрес не сохранён и доступность ADB сейчас не проверена.

Источник: README.md, версия репозитория `c68a372`.

## Что считать при появлении доступа

С компьютера в сети проектора либо через настроенный разрешённый VPN выполните
следующие команды с актуальным адресом. Если ADB требует подтверждения,
разрешите подключение на самом проекторе.

```sh
adb connect PROJECTOR_IP:5555
adb -s PROJECTOR_IP:5555 shell getprop ro.product.manufacturer
adb -s PROJECTOR_IP:5555 shell getprop ro.product.brand
adb -s PROJECTOR_IP:5555 shell getprop ro.product.model
adb -s PROJECTOR_IP:5555 shell getprop ro.product.device
adb -s PROJECTOR_IP:5555 shell getprop ro.build.version.release
adb -s PROJECTOR_IP:5555 shell getprop ro.build.version.sdk
adb -s PROJECTOR_IP:5555 shell getprop ro.product.cpu.abilist
adb -s PROJECTOR_IP:5555 shell getprop ro.build.display.id
```

После чтения внесите результаты в этот файл с датой проверки. Значение
`ro.product.model` может обозначать платформу: торговую модель подтверждайте
также разделом «Об устройстве» или маркировкой корпуса. Не сохраняйте пароли,
ключи ADB, серийные номера и VPN-конфигурацию.
