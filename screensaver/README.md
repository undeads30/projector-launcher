# Заставка с озером

Отдельное приложение ru.projector.digitalclock, версия 1.1: изображение озера на весь экран, часы и русская дата в нижнем правом углу. Исходное изображение адаптировано в JPEG для Android 9. Небольшой сдвиг положения раз в минуту и тень улучшают отображение часов.

Готовый APK: ../dist/DigitalClock.apk. Устанавливается отдельно с adb install -r, затем выбирается системной заставкой Android. Не включён в APK лаунчера.

Сборка Windows:

```powershell
./build.ps1 -Toolchain C:/AndroidToolchain -SigningKey C:/Private/launcher-debug.keystore
```

Ожидается структура Toolchain: jdk17/jdk-17.0.20+8, sdk/build-tools/34.0.0, sdk/platforms/android-34/android.jar. Ключ для совместимого обновления владелец хранит локально; он не включён в репозиторий. Выход: ../dist/DigitalClock.apk. Стандартные Android debug alias/password используются только для локального debug keystore.

На исходном проекторе установка и внешний вид проверены. После полного отключения питания системные дата и время могут требовать синхронизации; заставка использует системные часы.
