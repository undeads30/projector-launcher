# Projector Launcher — 2.1.0

Лаунчер и отдельные помощники для Cronus / Xiaomi XMJGYY01YS, Android 9, ARMv7.

[Скачать 2.1.0](https://github.com/undeads30/projector-launcher/releases/tag/v2.1.0) · [История версий](CHANGELOG.md) · [Сведения об устройстве](PROJECTOR.md)

## Возможности

- Папка «Наши приложения»: квадратные плитки, перенос приложений в обе стороны, сохранение состава и порядка, перемещение самой папки.
- Меню по ≡: открыть, переместить, перенести в папку/из папки, удалить с подтверждением. Общее оформление главного экрана и папки. Стрелки перемещают, ОК сохраняет, Назад отменяет.
- Компактные верхние кнопки, дата под часами, яркие надписи и баннер Kino. Общая чёрная подложка нижних плиток убрана.
- VPN HK / RU / OFF и три состояния: красный — нет VPN, оранжевый — доступ не подтверждён, зелёный — успешная HTTPS-проверка через SOCKS v2rayNG. Сохранена политика YouTube/HK, ВК/RU, Кино без VPN.
- Окно Wi-Fi с сетями и паролем, меню подключения, отключения без удаления пароля и забывания сохранённой сети.
- Локальные русские голосовые команды и поиск в Кино, YouTube и ВК Видео. С главного экрана появляется выбор сервиса. Назад отменяет запрос, новый запрос заменяет предыдущий. Автоматического воспроизведения нет.
- Боковая панель настроек: яркость, контрастность, насыщенность, проекция, громкость, выключатель звука, Wi-Fi, Bluetooth, голос и сведения об устройстве. Значения меняются внутри панели стрелками и ОК.

Резкость, температура цвета, масштаб, трапеция, дополнительные звуковые эффекты и новое Bluetooth-сопряжение остаются в системных настройках. Аппаратные ползунки изображения ограничены проверенным Cronus Android 9 / t982_ar301 / сборкой 1.8.150. Голос проверен на этом Android 9; поддержка других прошивок не гарантируется.

## Состав

| Каталог | Содержимое |
| --- | --- |
| launcher/ | Gradle-проект com.gathin.tvhome; зависимости скачиваются скриптом |
| hdmi-autoclose/ | Отдельное закрытие системных уведомлений HDMI, без смены входов |
| screensaver/ | Отдельная заставка с озером, часами и русской датой |
| cec-power/ | Штатное выключение по HDMI Standby для проверенной root-прошивки |
| dist/ | APK, JAR и контрольные суммы выпуска |

CEC-обработчик и заставка не включены в APK лаунчера и устанавливаются отдельно. Для обновления лаунчера их переустановка не нужна. Прошивка 908 и root-инструкция — в [отдельном репозитории](https://github.com/undeads30/cronus-908-root-guide).

## Установка

Скачайте APK из Releases. Обновление с -r сохраняет данные:

```sh
adb connect PROJECTOR_IP:5555
adb -s PROJECTOR_IP:5555 install -r LauncherTV-2.1.0.apk
adb -s PROJECTOR_IP:5555 shell am start -n com.gathin.tvhome/.MainActivity
```

Большой APK хранится в файлах релиза, а не в истории Git. Готовые APK подписаны прежним сертификатом исходного проектора. При несовпадении сертификата не удаляйте установленный лаунчер ради проверки: сначала выясните происхождение APK и сохраните данные.

VPN-профили настраиваются отдельно в v2rayNG. Для подписи HK/RU нужен доступ к уведомлениям:

```sh
adb shell cmd notification allow_listener com.gathin.tvhome/.VpnStatusService
```

Для голоса: [docs/VOICE.md](docs/VOICE.md). Службы специальных возможностей включайте по отдельности, сохраняя уже работающие службы VPN и HDMI.

## Сборка

JDK 17, Android SDK 34, Build Tools 34.0.0. Укажите SDK через ANDROID_HOME или локальный launcher/local.properties. На Windows используйте путь без кириллицы.

```sh
cd launcher
# First run download-dependencies.ps1 in PowerShell
./gradlew :app:testReleaseUnitTest :app:assembleRelease
```

Windows: gradlew.bat. Результат: launcher/app/build/outputs/apk/release/app-release.apk. Перед сборкой запустите launcher/download-dependencies.ps1: он скачает модель и два AAR из файлов релиза и проверит DEPENDENCIES.sha256. Модель включена в готовый APK, но не хранится в истории Git.

Ключ подписи не публикуется. Для совместимого обновления положите свою локальную копию в launcher/app/launcher-debug.keystore. Без неё используется локальный Android debug key; подпись может отличаться от установленного APK.

Помощник HDMI: ./hdmi-autoclose/build.ps1 -AndroidSdk $env:ANDROID_HOME. Для остальных компонентов смотрите их README.
