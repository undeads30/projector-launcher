# Выключение по HDMI Standby

Отдельный app_process-обработчик для проверенного Cronus / t982_ar301 с прошивкой 908 и уже имеющимся root. Не часть APK лаунчера. Реагирует на свежую команду HDMI Standby запросом штатного IPowerManager.shutdown без пробуждения экрана, дополнительных POWER и задержек. Есть защита от старых и повторных событий. Итоговый цикл выключения/включения через Алису и автозапуск подтверждены владельцем.

Пока обработчик активен, он удерживает ограниченный по времени, регулярно обновляемый CPU wake lock; обычный сон с погасшим экраном не переводит CPU в deep sleep. Полное штатное выключение остаётся доступным. Требуется уже настроенное ro.vendor.platform.wifi.suspend=false: скрипт установки его сам не меняет. Это изменение окружения исходного проектора предотвращает штатное отключение Wi-Fi при HDMI-сне. SELinux остаётся Enforcing.

Сборка Windows: ./build.ps1 -Toolchain C:/AndroidToolchain. В Toolchain ожидаются jdk17/jdk-17.0.20+8 и sdk/build-tools/34.0.0, sdk/platforms/android-34/android.jar. Результат: dist/cec-power.jar внутри этого компонента. JVM-проверки находятся в test/; классы тестов содержат main.

deploy/ содержит отдельные install/update/uninstall, init rc и run.sh. Изучите их до применения. Начальная установка отказывается заменять существующие файлы, пишет только свои три системных файла и возвращает / в read-only; она требует root и перезагрузки для загрузки нового init rc. Это не универсальный установщик для других Android TV. Изменение Wi-Fi-свойства и установка root автоматически не выполняются.

Для подготовленной установки файлы cec-power.jar, cec-power.rc, run.sh и install.sh помещаются в /data/local/tmp/cec-power-install/. Скрипт вызывается root-командой su 0 sh /data/local/tmp/cec-power-install/install.sh. Не выполняйте его на несовместимой прошивке. Для удаления только компонента используйте deploy/uninstall.sh. Настройки VPN, лаунчер и системные APK не заменяются.
